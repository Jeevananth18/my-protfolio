## 🚀 How to Run Locally

Since this project is built with clean Vanilla HTML5, CSS3, and JavaScript, no build tools or package managers are required!

### Option 1: Direct Double Click
Simply double-click `index.html` to open it directly in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Live Server (VS Code)
1. Open the folder in **Visual Studio Code**.
2. Right-click `index.html` and select **"Open with Live Server"**.

### Option 3: Python / Node Local Server
```bash
# Using Python:
python -m http.server 8000

# Using Node / npx:
npx serve .
```
Visit `http://localhost:8000` in your browser.

## 🌐 Free 1-Minute GitHub Pages Deployment Guide

To get a live sharable link for recruiters (e.g. `https://Jeevananth18.github.io/jeeva-portfolio`):

1. Initialize Git in this directory (if not already):
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Recruiter-ready portfolio website"
   ```
2. Create a new repository on your GitHub account (`https://github.com/new`) named `jeevananth-portfolio` or `jeevananth.github.io`.
3. Push your code:
   ```bash
   git remote add origin https://github.com/Jeevananth18/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```
4. Go to **GitHub Repository Settings** ➔ **Pages** ➔ Under **Source**, select **`Deploy from a branch`** ➔ Choose **`main`** / **`/ (root)`** and click **Save**.
5. Your portfolio will be live in 60 seconds!
